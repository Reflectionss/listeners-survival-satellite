Place replacement zone photographs here, then set the paths in js/zones.js:

  image:     "images/zone01.jpg"   (thumbnail + default viewer image)
  imageFull: "images/zone01_full.jpg"  (optional, larger photo in the viewer)

Each zone is configured independently. Leave `image: null` to use the stand-in live capture.
Recommended: 16:9 landscape, 1600x900 or larger.
